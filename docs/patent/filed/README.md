## 公開方針(本公開リポジトリとしての選択)

- **出願の時点で発明者(Kuroki Yasuhiro)は法的権利を保有**。`filed/` の PDF を公開しなくても、特許としての新規性・優先権は確保済
- **JPO 自動公開前の先行公開は、国際特許出願(PCT)の戦略判断を制約する可能性**。2027-02-24(Paris 条約優先権期間終了)までに PCT 出願の意思を固めた後、あるいは JPO 自動公開後に本ディレクトリへ追加する
- **発明の技術的中身は、[`paper.pdf`](../../arxiv_submission/paper.pdf) に詳述済**。機械学習研究者が KDF を理解するための素材は揃っている

## JPO の自動公開時期

> 特許法 第64条(出願公開)に基づき、特許出願の日から **1年6ヶ月** を経過したときは、特許庁長官がその出願を公開する。

本出願は 2026-02-24 付なので、通常フローで **2027-08-24 頃** に公開される見込み。その時点で本 `filed/` ディレクトリに PDF を追加予定。
